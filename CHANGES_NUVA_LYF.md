# NUVA LYF website updates

This package is the rebranded NUVA LYF version of the supplied website.

## Updated

- Replaced public-facing **NUVA Health** branding with **NUVA LYF**.
- Updated page metadata, logo accessibility labels, footer copy, CTA copy, company/about copy, and developer documentation.
- Renamed the package to `nuva-lyf-website`.
- Changed the product section eyebrow to **NUVA LYF Product Platform**.
- Improved the platform workflow selector with clear icons and stronger interaction states.
- Added a distinct teal/navy hover state so the **Front Desk** option and other tabs remain visible when hovered.
- Added visible focus treatment for keyboard users and preserved a high-contrast selected state.
- Added pointer cursor and subtle lift/shadow feedback to make clickable options clearer.

## Run locally

1. Install Node.js 22.13 or newer.
2. Run `npm install` (or `pnpm install`).
3. Run `npm run dev`.
4. Open the local URL printed in the terminal.
